# Clínica — Brand Assets

Repositorio de assets visuales para la identidad de marca de una clínica médica.

## 🎨 Paleta de marca

| Color | Nombre | HEX | Uso |
|-------|--------|-----|-----|
| 🟫 | Grain Brown | `#CBB8A2` | Dominante 60% — pieles, texturas, luz ambiental |
| 🟩 | Tinny Tin | `#44492B` | Secundario 30% — batas, fondos, sombras medias |
| ⬛ | Marshland | `#252922` | Acento 10% — profundidad, sombras, bordes oscuros |
| 🟤 | Vast Desert | `#C2AF96` | Dominante alterno — sand/beige cálido |

**Sistema de color 60:30:10** — beige cálido dominante / verde oliva secundario / casi-negro de acento.
